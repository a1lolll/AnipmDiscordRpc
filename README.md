# ani.pm Discord Rich Presence

a chrome extension that syncs what you are watching on ani.pm directly to your Discord status.

## What does it do?
it basically just shows what ur watching and what episode and all on ani.pm but as a discord rpc status

## Setup
1. download this repository.
2. go to `chrome://extensions/` or `brave://extensions/` in your browser.
3. enable **Developer mode**.
4. click **Load unpacked** and select the folder containing these files.
5. add your Discord token in the extension popup.
